# MI production preview

This preview plans deterministic production in the supported StaTech Industry 2.0.1 catalog. Give it a recipe and an output goal; it calculates connected material flows, whole machine counts, upgrade loadouts, and production power. Use the graph to inspect every supply and requested output, then export a portable plan before making major changes.

New plans enable all obtainable, supported machines and upgrades, with external electricity. Open Settings to apply an earlier progression preset or change individual machines, upgrades, and supplies. The goal editor accepts a decimal rate, an exact fraction per second such as `1/3600`, a finite quantity, or a fixed machine capacity. A quantity's time starts after startup.

Click a recipe node to see its suppliers and consumers in the inspector. Click a relationship to jump to that node; direct suppliers and consumers have distinct highlights. For an output with several recipes, choose **Choose source** under Production routes. For a recipe input with alternatives, choose **Choose ingredient** under Ingredient choices. Search the list, select the wanted entry, and use **Use choice**. **Automatic choice** clears that selection, including the recipe on a rate goal. Pinning an intermediate does not add another output goal. **Configure production line** changes its machine or upgrades without changing retained demand. Undo restores prior choices.

The graph starts with material links visible; choose All flows to include power links or Selected flows for a direct neighborhood. Focus chain centers the selected recipe and nearby inputs. Pan with middle drag and zoom with Ctrl + wheel, down to 3%. Arrange rebuilds the layout as connected neighborhoods and routes connections around cards. Use it once to update a plan saved by an older version; ordinary recalculation keeps manual positions and groups. Expand graph gives the canvas the full workspace width; Escape restores the side panels. Local External EU badges show each line's share of the configured electricity supply. New plan clears a restored example or old workspace and starts with the bundled StaTech catalog. Undo restores the previous workspace. **Plan details** above the graph shows running draw, external supply, and the sum of installed machine peak ratings. That peak is the simultaneous rated maximum of every installed machine, not a measured operating load.

The selected deterministic production balances are exact. Long fractions appear as compact values with an ellipsis; hover over a value for its full exact fraction. Power totals use readable rounded units with the full exact value in a tooltip. A feasible plan may still use a more expensive route than another available choice. Recipes with random outputs show expected yields rather than guaranteed amounts. Replicatorless plans exclude the loaded UU-to-item Matter Fabricator routes, including potatoes made from UU matter. Ordinary UU-consuming recipes remain available. Unsupported recipes and missing obtained resources remain visible. This preview does not automatically plan generators, prove the cheapest full late-game factory, or provide verified warm-up stock buffers. World ZIP reconstruction and non-MI process coverage remain incomplete. Transfer capacity in pipes or cables is not a planning constraint.

For Windows, extract the entire Windows archive and run `FactoryPlanner.exe` beside its `.pck`, `runtime`, `kernel`, and `node_modules` folders. No Minecraft installation or extraction tool is needed. Plans save locally and can be exported as JSON. The browser build also keeps plans locally when IndexedDB is available; export a JSON backup, especially in private or embedded browsing. Import that JSON with the application's Import button to move a plan between builds. A different modpack can supply its own format-1 planning dataset through the same import path; see the repository's `docs/dataset-format.md` for the schema.

To publish on itch.io, upload the `*-itch.zip` archive as an HTML game. Keep `index.html` and all other files at the ZIP root. Use a fullscreen launch or an embedded view of at least 1280 × 720. The project page should identify the app as an unofficial Minecraft companion, link to the StaTech and mod attribution in the archive, and provide a publisher contact. The web archive uses relative files and a single-threaded Godot export; it does not require cross-origin isolation headers.

The bundled catalog records pack and mod versions, source hashes, licenses, and explicit unsupported entries. `PREVIEW.md` and the `notices` folder travel with each archive. [Issue #2](https://github.com/kurushimee/sti2-factory-planner/issues/2) tracks the complete product after this preview has been tested by players.
